# Угадай число
  Нужно написать программу, которая угадывает число за минимальное число попыток. Алгоритм, который мы используем для угадывания числа, называется бинарным поиском. Этот алгоритм эффективен для поиска элемента в отсортированном диапазоне чисел. Вот основные шаги алгоритма:
 
## Условия
* Определение границ: Устанавливаем начальные границы диапазона, в данном случае от 1 до 100.

* Предположение: Находим среднее значение между границами (low и high) и делаем его нашим предположением.

# Сравнение: Сравниваем предположение с загаданным числом:
* Если предположение меньше загаданного числа, мы сдвигаем нижнюю границу (low) вверх, чтобы исключить все числа ниже текущего предположения.
* Если предположение больше загаданного числа, мы сдвигаем верхнюю границу (high) вниз, чтобы исключить все числа выше текущего предположения.
* Повторение: Повторяем шаги 2 и 3, пока предположение не совпадет с загаданным числом.
# Вывод
* Подсчет попыток: Считаем количество попыток, необходимых для угадывания числа.
